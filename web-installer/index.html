Install QRPickle on a Cheap Yellow Display

Version: loading…

  1. Use Chrome or Edge on a computer (Web Serial is required).
  2. Connect the CYD with a USB data cable.
  3. Click Install, pick the serial port, and allow erasing for a clean install.

After installing, the device opens a QRPickle-Setup WiFi network. Its password and the web console login are shown on the device's Network screen.

Already running QRPickle? Update over WiFi instead: sidebar → Cloud OTA.
