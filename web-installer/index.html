Install QRPickle on a Cheap Yellow Display

QRPickle is a field-friendly ham radio dashboard for the ESP32 "Cheap Yellow Display". Read about it in the QRPickle article.

This is an older version. Installing it replaces the firmware and the web console files; with "Erase device" it also clears all settings. Cloud OTA will offer newer versions again afterwards.

  1. Use Chrome or Edge on a computer (Web Serial is required).
  2. Connect the CYD with a USB data cable.
  3. Click Install QRPickle, pick the serial port, and allow erasing for a clean install.
This browser can't access USB serial ports. Use Chrome or Edge on a computer. The installer needs a secure (https) page.
What gets written where

Every version uses the same flash layout:

AddressFileContents
0x1000bootloader.binESP32 bootloader
0x8000partitions.binPartition table
0xE000boot_app0.binotadata: boot from app0
0x10000firmware.binFirmware (app0)
0x390000littlefs.binWeb console files (LittleFS)

Settings (nvs, 0x9000) are kept unless you erase the device.

After installing, the device opens a QRPickle-Setup WiFi network. Its password and the web console login are shown on the device's Network screen.

Already running QRPickle v0.2.0 or later? Update over WiFi instead: Cloud OTA on the device or in the web console. Older versions need this installer once. Erasing also clears your settings and profiles, so download a backup first (web console → Profiles → Download Backup) where available.
