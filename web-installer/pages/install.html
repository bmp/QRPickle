Install QRPickle on a Cheap Yellow Display

What you need

  • An ESP32-2432S028R "Cheap Yellow Display": the 2.8" version with a resistive touch screen (ESP32, 4 MB flash, ILI9341 display, XPT2046 touch). Nothing needs soldering. The 3.2" ESP32-2432S032 is not supported (different display and pins).
  • A USB data cable (some cables only charge) and a computer with Chrome or Edge.
  • Optional: a BME280 sensor on the CN1 connector for indoor temperature, humidity and pressure.
  • A 2.4 GHz WiFi network.

Pins, wiring and board details: Hardware and Wiring in the manual.

    What gets written where
    
Every version uses the same flash layout:

    

      
AddressFileContents

      
      
0x1000bootloader.binESP32 bootloader

      
0x8000partitions.binPartition table

      
0xE000boot_app0.binotadata: boot from app0

      
0x10000firmware.binFirmware (app0)

      
0x390000littlefs.binWeb console files (LittleFS)

      
    

    
Settings (nvs, 0x9000) are kept unless you erase the device.

  

  
After installing, the device opens a QRPickle-Setup WiFi network. Its password and the web
     console login are shown on the device's Network screen. Join it, open http://192.168.4.1 (user
   admin, the same password) and enter your WiFi network, callsign and grid square; the device then
   joins your network.


The CYD has no battery-backed clock: at every start it sets its time from the internet (NTP) as soon as it is
   on WiFi, and the clock shows --:-- until then. UTC is always right; for local time set your UTC
   offset in Settings (half-hour steps, no automatic daylight saving).

  
Already running QRPickle v0.2.0 or later? Update over WiFi instead: Cloud OTA on the device or in the web console.
     Older versions need this installer once. Erasing also clears your settings and profiles, so download a
     backup first (web console → Profiles → Download Backup) where available.
